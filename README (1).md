# GRE6 Tunnel Manager

اسکریپت منوی‌دار برای ساخت تانل **GRE روی بستر IPv6** (`ip6gre`) بین سرور ایران و سرور خارج.

- نصب خودکار پیش‌نیازها
- تنظیم سمت ایران و دریافت **کد هش**
- تنظیم سمت خارج فقط با paste کردن کد هش
- پایدار بعد از ریبوت (systemd)
- پورت‌فوروارد از ایران به خارج
- watchdog برای ریستارت خودکار تانل

---

## نصب و اجرا

روی هر دو سرور و با کاربر root:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/imahdavii/gre6-tunnel/main/gre6.sh)
```

> به‌جای `USERNAME` و `REPO` یوزرنیم و اسم ریپوی خودتان را بگذارید.
> از `curl ... | bash` استفاده نکنید، چون منو ورودی کاربر را نمی‌گیرد.

بعد از اولین اجرا، دفعات بعد فقط این دستور را بزنید:

```bash
gre6
```

اگر سرور ایران به GitHub دسترسی ندارد، فایل `gre6.sh` را روی سرور خارج دانلود کنید، با `scp` به ایران بفرستید و اجرا کنید:

```bash
bash gre6.sh
```

---

## پیش‌نیازها

- هر دو سرور **IPv6 عمومی** داشته باشند و بین‌شان ping6 کار کند.
- پروتکل **GRE (شماره ۴۷)** روی فایروال دو سرور و دیتاسنتر باز باشد.
- دسترسی root.
- سیستم‌عامل لینوکس (Ubuntu / Debian / CentOS / Alpine تست‌شده در منطق نصب).

---

## مراحل راه‌اندازی

### ۱. سرور ایران
گزینه **1** را بزنید و این‌ها را وارد کنید:

| مورد | توضیح |
|---|---|
| نام تانل | حروف و عدد، حداکثر ۱۵ کاراکتر |
| IPv6 ایران | به‌صورت خودکار تشخیص داده می‌شود |
| IPv6 خارج | آدرس IPv6 سرور خارج |
| شماره ساب‌نت | عدد ۱ تا ۲۵۰ |
| MTU | پیش‌فرض ۱۳۸۰ |

بعد از ساخت تانل، یک کد به شکل `GRE6-...` چاپ می‌شود. آن را کپی کنید.

### ۲. سرور خارج
گزینه **2** را بزنید و کد هش را paste کنید. بقیه‌چیز خودکار تنظیم می‌شود.

### ۳. تست
گزینه **4** را بزنید یا دستی ping کنید:

```bash
# از ایران
ping -6 fd00:N::2
# از خارج
ping -6 fd00:N::1
```

به‌جای `N` شماره ساب‌نتی که وارد کردید را بگذارید.

## آدرس‌های داخلی تانل

| سرور | IPv6 داخلی |
|---|---|
| ایران | `fd00:N::1` |
| خارج | `fd00:N::2` |

## منو

| گزینه | کار |
|---|---|
| 1 | راه‌اندازی سرور ایران و ساخت کد هش |
| 2 | راه‌اندازی سرور خارج با کد هش |
| 3 | نمایش دوباره کد هش |
| 4 | وضعیت و تست ping |
| 5 | پورت‌فوروارد (سمت ایران) |
| 6 | watchdog (ریستارت خودکار) |
| 7 | ریستارت تانل |
| 8 | حذف تانل |
| 9 | نصب دوباره پیش‌نیازها |

### پورت‌فوروارد
فقط روی سرور ایران کار می‌کند و با ip6tables ترافیک پورت‌های انتخابی را به آدرس IPv6 داخلی سرور خارج می‌فرستد. نمونه ورودی‌ها:

```
443
80,443,8443
2000-3000
```

ورودی خالی یعنی غیرفعال کردن فوروارد.

---

## نکات امنیتی

- کد هش شامل **آدرس‌ها، نام تانل و شماره ساب‌نت** است و چک‌سام دارد. این کد کلید رمزنگاری نیست.
- پروتکل GRE **رمزنگاری ندارد**. اگر به محرمانگی نیاز دارید، روی تانل از پروتکل رمزنگاری‌شده (مثل WireGuard یا TLS) استفاده کنید.
- کد هش را در جای عمومی منتشر نکنید.

## فایل‌های ساخته‌شده روی سرور

| مسیر | کار |
|---|---|
| `/etc/gre6tunnel/NAME.conf` | تنظیمات هر تانل |
| `/usr/local/bin/gre6` | خود اسکریپت (برای باز کردن منو) |
| `/etc/systemd/system/gre6@.service` | سرویس تانل |
| `/etc/systemd/system/gre6-watch@.timer` | تایمر watchdog |

حذف کامل یک تانل از منو با گزینه **8** انجام می‌شود.

---

## عیب‌یابی

- **ping جواب نمی‌دهد:** مطمئن شوید GRE روی فایروال هر دو سرور و دیتاسنتر باز است و ping6 بین دو IPv6 کار می‌کند.
- **کد هش نامعتبر است:** کد را کامل و بدون فاصله یا خط اضافه کپی کنید.
- **سایت‌ها یا سرویس‌ها کند یا قطع‌وصل هستند:** مقدار MTU را کمتر کنید (مثلاً ۱۳۰۰) و تانل را دوباره بسازید.
- **لاگ سرویس:** `journalctl -u gre6@NAME -e`
