# GRE6 Tunnel Manager

اسکریپت منوی‌دار برای ساخت تانل **GRE روی IPv4** که **داخلش فقط IPv6** است، بین سرور ایران و سرور خارج.

برای راه‌اندازی فقط **IPv4 عمومی دو سرور** لازم است. آدرس IPv6 داخل تانل از روی IPv4 ساخته می‌شود:

```
140.233.177.59  ->  2002:8ce9:b13b::1
185.126.15.41   ->  2002:b97e:0f29::1
```

- نصب خودکار پیش‌نیازها (python3، pip، colorama، netifaces، curl، iproute2، iptables)
- تنظیم سمت ایران و دریافت **کد هش**
- تنظیم سمت خارج فقط با paste کردن کد هش
- آدرس IPv6 اضافه به تعداد دلخواه
- پایدار بعد از ریبوت (systemd)
- ping keepalive با ریستارت خودکار تانل

---

## نصب و اجرا

روی هر دو سرور و با کاربر root:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/imahdavii/gre6-tunnel/main/gre6.sh)
```

> از `curl ... | bash` استفاده نکنید، چون منو ورودی کاربر را نمی‌گیرد.

بعد از اولین اجرا، دفعات بعد فقط این دستور را بزنید:

```bash
gre6
```

اگر سرور ایران به GitHub دسترسی ندارد، فایل `gre6.sh` را روی سرور خارج دانلود کنید، با `scp` به ایران بفرستید و اجرا کنید:

```bash
bash gre6.sh
```

---

## پیش‌نیازها

- هر دو سرور **IPv4 عمومی** داشته باشند.
- پروتکل **GRE (شماره ۴۷)** روی فایروال دو سرور و دیتاسنتر باز باشد.
- دسترسی root.
- سیستم‌عامل لینوکس (Ubuntu / Debian مبنای تست منطق نصب است).

اسکریپت خودش این‌ها را نصب می‌کند: `iproute2`، `iptables`، `curl`، `openssl`، `python3`، `pip`، `colorama` و `netifaces`.

---

## مراحل راه‌اندازی

### ۱. سرور ایران
گزینه **1** را بزنید و این‌ها را وارد کنید:

| مورد | توضیح |
|---|---|
| نام تانل | حروف و عدد، حداکثر ۱۵ کاراکتر |
| IPv4 ایران | به‌صورت خودکار تشخیص داده می‌شود |
| IPv4 خارج | آدرس IPv4 سرور خارج |
| تعداد IPv6 اضافه | پیش‌فرض ۱ |
| MTU | بین ۱۲۸۰ تا ۱۴۷۶، پیش‌فرض ۱۴۰۰ |

بعد از ساخت تانل، یک کد به شکل `GRE6-...` چاپ می‌شود. آن را کپی کنید.

### ۲. سرور خارج
گزینه **2** را بزنید و کد هش را paste کنید. بقیه‌چیز خودکار تنظیم می‌شود و در پایان ping تست هم زده می‌شود.

### ۳. تست
گزینه **4** را بزنید یا دستی ping کنید:

```bash
# از ایران (آدرس IPv6 سرور خارج)
ping -6 2002:8ce9:b13b::1
# از خارج (آدرس IPv6 سرور ایران)
ping -6 2002:b97e:0f29::1
```

آدرس‌های بالا نمونه هستند. آدرس‌های خودتان در انتهای راه‌اندازی چاپ می‌شود.

---

## آدرس‌های داخلی تانل

هر سرور آدرس `2002:xxxx:xxxx::1` از روی IPv4 خودش می‌گیرد. اگر IPv6 اضافه بخواهید، آدرس‌های `::2`، `::3` و ... هم روی همان سرور ساخته می‌شود.

## منو

| گزینه | کار |
|---|---|
| 1 | راه‌اندازی سرور ایران و ساخت کد هش |
| 2 | راه‌اندازی سرور خارج با کد هش |
| 3 | نمایش دوباره کد هش |
| 4 | وضعیت و تست ping |
| 5 | ping keepalive و ریستارت خودکار |
| 6 | ریستارت تانل |
| 7 | حذف تانل |
| 8 | نصب دوباره پیش‌نیازها |

---

## نکات امنیتی

- کد هش شامل **IPv4 دو سرور، نام تانل، تعداد IPv6 اضافه و MTU** است و چک‌سام دارد. این کد کلید رمزنگاری نیست.
- پروتکل GRE **رمزنگاری ندارد**. اگر به محرمانگی نیاز دارید، روی تانل از پروتکل رمزنگاری‌شده (مثل WireGuard یا TLS) استفاده کنید.
- کد هش را در جای عمومی منتشر نکنید.

---

## فایل‌های ساخته‌شده روی سرور

| مسیر | کار |
|---|---|
| `/etc/gre6tunnel/NAME.conf` | تنظیمات هر تانل |
| `/usr/local/bin/gre6` | خود اسکریپت (برای باز کردن منو) |
| `/etc/systemd/system/gre6@.service` | سرویس تانل |
| `/etc/systemd/system/gre6-watch@.timer` | تایمر ping keepalive |

حذف کامل یک تانل از منو با گزینه **7** انجام می‌شود.

## عیب‌یابی

- **ping جواب نمی‌دهد:** مطمئن شوید سمت ایران هم ساخته شده، و GRE (پروتکل ۴۷) روی فایروال هر دو سرور و دیتاسنتر باز است. اگر سرور خارج را قبل از ایران ساخته باشید، ping اول طبیعی است که جواب ندهد.
- **ساخت تانل خطا می‌دهد:** IPv4 واردشده باید دقیقاً یکی از آدرس‌های همان سرور باشد. اگر سرور پشت NAT است، IP داخلی سرور را به‌عنوان IPv4 خودش وارد کنید.
- **کد هش نامعتبر است:** کد را کامل و بدون فاصله یا خط اضافه کپی کنید.
- **سرویس‌ها کند یا قطع‌وصل هستند:** مقدار MTU را کمتر کنید (مثلاً ۱۳۰۰) و تانل را دوباره بسازید.
- **لاگ سرویس:** `journalctl -u gre6@NAME -e`
